# Gemini Project Context: slack-export-viewer

This document provides context for the `slack-export-viewer` project for the Gemini AI assistant.

## Project Overview

`slack-export-viewer` is a desktop application built with Wails. It allows users to view and analyze Slack export files. The application has a Go backend and a Svelte frontend. The user can drag and drop a Slack export zip file, and the application will process it.

## Technologies

- **Backend**: Go
- **Frontend**: Svelte, TypeScript, Vite
- **Framework**: Wails
- **Database**: SQLite

## Project Structure

- `main.go`: The main entry point for the Go backend. It handles application startup, window creation, and defines methods that can be called from the frontend.
- `go.mod`, `go.sum`: Go module files, defining project dependencies.
- `wails.json`: The Wails project configuration file. It defines the project name, build commands, and other settings.
- `frontend/`: The directory containing the Svelte frontend code.
  - `frontend/src/App.svelte`: The main Svelte component.
  - `frontend/src/main.ts`: The entry point for the frontend application.
  - `frontend/package.json`: Defines frontend dependencies and scripts.
  - `frontend/wailsjs/`: Contains the JavaScript bindings for the Go backend, generated by Wails.
- `build/`: Contains build-related files, like icons and platform-specific configuration.

## Build Commands

- **Development**: `wails dev` - Runs the application in live development mode.
- **Production Build**: `wails build` - Builds a redistributable, production-ready package.

## Backend (Go)

The Go backend is responsible for:

- Handling the application lifecycle (`startup`).
- Managing SQLite database connections. Handling file drops (`onFileDrop`).
- Processing the Slack export zip file (`Import`).
- Exposing methods to the frontend, such as `GetViewState`.

## Frontend (Svelte)

The Svelte frontend is responsible for:

- Providing the user interface.
- Interacting with the Go backend through the methods defined in `frontend/wailsjs/go/main/App.js`.
- Displaying different views based on the application state (`setup`, `dashboard`, `loading`).
- Handling user interactions, such as file uploads.
